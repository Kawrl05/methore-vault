# Privacy-Personalization Tradeoff

## Definition
A term used by [[Ojokoh et al 2025]] (citing [[Klostermann Kluy 2025]]) to describe how the same user data that recommendation algorithms need for effective personalization is also the data that creates opportunities for privacy violations and profiling.

## Key Details
- Personalization and privacy protection pull in opposite directions: better recommendations generally require more granular behavioral data.
- [[Zakhary et al 2019]] proposed one mitigation — randomly injecting unrelated topic suggestions to obscure a user's true attribute profile — but this doesn't address platform transparency about data use.
- This tradeoff, combined with unclear platform transparency, is the central gap Gab's topic aims to address through a gamified evaluation approach.
