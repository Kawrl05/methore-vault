# Social Media Recommendation Algorithms

## Definition
Systems that curate the content a user sees on a platform, generally optimized to maximize engagement/time-on-site rather than purely to inform.

## Key Details
- [[Narayanan 2023]] describes the evolution from manually-set weighting rules (Facebook, 2010) to machine-learning systems that automatically learn which interactions predict continued engagement (Facebook, by 2018).
- These systems can build detailed behavioral profiles without users directly disclosing that data — e.g., Netflix users suspecting race-based thumbnail personalization, which Netflix denies collecting as a data point.
- This profiling capability is the root of the concern explored in [[Privacy-Personalization Tradeoff]].
